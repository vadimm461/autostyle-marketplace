AUTO STYLE — уведомления

Что добавлено:
1. Слоган под логотипом: "все для движения вперед".
2. Иконки для профиля, избранного и корзины.
3. Количество товаров/избранного показывается бейджем над кнопкой.
4. В профиле добавлен блок "Уведомления".
5. В админке добавлен блок "Уведомление всем пользователям".
6. Добавлен файл firebase-messaging-sw.js — заготовка под настоящие push-уведомления.

Важно:
Сейчас уведомления сохраняются в интерфейсе/Firestore при наличии подключенного db.
Чтобы уведомления реально прилетали на главный экран телефона как push, нужно подключить Firebase Cloud Messaging:
- включить Cloud Messaging в Firebase;
- добавить VAPID key;
- сохранять FCM-токены пользователей;
- отправлять push через Cloud Functions или сервер.
