AUTO STYLE — уведомления

Исправлено:
- иконки и бейджи работают только в верхней шапке;
- уведомления вынесены отдельной кнопкой в верхнее меню;
- уведомления убраны из профиля;
- дублирующийся "Аккаунт" в шапке автоматически удаляется;
- слоган стоит под логотипом AUTO STYLE.

Для настоящих push-уведомлений на экран телефона нужно подключить Firebase Cloud Messaging:
1. включить Cloud Messaging в Firebase;
2. добавить VAPID key;
3. получать и сохранять FCM-токены пользователей;
4. отправлять push через Cloud Functions или свой сервер.
