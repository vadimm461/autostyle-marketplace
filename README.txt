ИСПРАВЛЕНИЕ ПЕРВОГО ОТКРЫТИЯ МОБИЛЬНОГО САЙТА

Проблема:
после долгого простоя Firebase, сетевой запрос или старый Service Worker могли
зависнуть до завершения инициализации. Загрузчик оставался поверх страницы,
из-за чего пользователь видел белый экран. Переход по другой кнопке запускал
страницу повторно, и она уже открывалась.

Исправлено:
- загрузчик принудительно снимается максимум через 4,2–4,5 секунды;
- запрос проверки версии кэша ограничен 2,5 секундами;
- запрос коллекций ограничен 7 секундами;
- свежий локальный кэш показывается сразу, без ожидания Firestore;
- после выхода телефона из долгого сна выполняется мягкое обновление;
- ошибка Firebase или старого Service Worker больше не закрывает интерфейс;
- изменены версии файлов во всех mobile*.html для обхода старого кэша.

Заменить файлы с сохранением папок.
