AutoStyle HTML + Firebase

1. Открой js/firebase.js
2. Вставь данные Firebase config
3. В Firebase включи Authentication -> Email/Password
4. Создай Firestore Database
5. Включи Storage
6. Загрузи все файлы в корень сайта/хостинга

Страницы:
index.html - главная
catalog.html - каталог
login.html - вход
register.html - регистрация
admin.html - админка и добавление товара
