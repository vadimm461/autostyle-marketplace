AutoStyle Modern HTML — separate Firebase collections

1. Открой js/firebase.js
2. Вставь свой apiKey вместо PASTE_API_KEY
3. Загрузи все файлы в GitHub в корень репозитория
4. GitHub Pages: main / root

Этот архив использует отдельные коллекции Firebase:
- autostyle_products
- autostyle_categories
- autostyle_banners
- autostyle_users

Если используешь Firestore Rules, добавь эти коллекции в правила чтения/записи.
